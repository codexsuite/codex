Bottom menu

Inside a book: Plan · Write · Knowledge · Settings, every tab acting on the open book. Library is the root screen with no tab bar; ‹ in the top bar returns to it, and tapping the book title opens the book switcher (recent books, then All books in Library). Pushed screens keep their parent tab selected. The tab bar hides while the keyboard is up. Record has no tab: it starts from a scene or an entry, so its target is always known.

Sign in

The first screen on a fresh install, and after Sign out. Codex is self-hosted, so the app asks for the server address as well as email and password. The server is checked as soon as you leave the field (GET /api/health, anonymous), so a typo shows up before the password does. No tab bar, no book bar. After signing in the app opens Library and keeps the token in the device keychain, so the screen is not seen again until Sign out.

Screens

Real size (390 × 844 pt class, iPhone 15/16). Phones scroll. Sample book: Hollow Throne, Book 3 of The Ashen Crown, so the Knowledge base shows the series-shared case.

Drill-ins and sheets

Detail views open as pushed screens (entry, style guide) or bottom sheets (scene, record, chapter jump, book switcher), so the tab bar stays put and Back always means one level up.
